# 患者流程（PATIENT-FLOW）· 三流骨架（M1 填实）

流一：手术与病理（确诊）——"乳头状癌""VI 期""风险分层"读不懂；声音哑了、手麻了 → 我的瘤（病理/分层引用）+ 并发症双线。产物：分层摘要 + 并发症记录。
流二：碘治疗与调药（治疗期）——碘131 要隔离几天？优甲乐为什么加减量？→ 碘治疗档案 + 剂量时间线与 TSH 目标并列。产物：治疗档案 + 问题清单。
流三：终生随访（长程）——半年一次 Tg、一年一次超声，"癌但要跟一辈子" → 长程随访日历 + 超声并列 + 试验线索。产物：复诊摘要（private 过滤）+ 随访节奏语境。

反推原则同家族：两条流经过 → 一级；无流 → 不做；与 cervical 重名率 ≤70% 实测。
