## 二、CRUD 双通道矩阵（按实体填全：AI 默认列 + 手工收敛列 + 红线列）

| 实体 | AI 协助（默认） | 手工（收敛入口） | 红线 |

| 甲功抄单（Tg/TgAb/TSH/FT4） | 拍化验单→候选（状态口径自动标注） | 「＋ 抄一次化验单」5 字段（日期/Tg/TgAb/TSH/状态来源） | 数值照抄；不判达标；Tg 升高≠复发（T4） |
| 剂量调整（优甲乐） | 医嘱拍照→候选 diff | 「＋ 登记剂量变更」3 字段（日期/剂量/医嘱原文），登记=新增版本 | **零"建议调整剂量"文案**（T2） |
| 碘治疗事件 | 治疗单/出院记录解析→候选 | 「＋ 登记碘治疗事件」5 字段（日期/类型/剂量/隔离天数/出院指导原文） | 不做适应症判断（T3）；剂量照治疗单抄 |
| 隔离防护打卡 | 出院指导原文拆条→候选 | checklist 勾选（按家庭成员快照触发） | 防护范围只按出院指导原文，不新增要求 |
| 超声登记 | 报告解析→候选（分类/测量/当时 Tg） | 「＋ 登记超声报告」4 字段 | TI-RADS 只抄体系名+原文，零判读列（T5） |
| 声音日记 | 对话"今天又哑了"→候选 | 「＋ 记一条声音日记」3 字段（日期/状态单选/备注） | 不判神经损伤；暂时/永久标注归医生（T6 并发症） |
| 血钙/PTH 抄单 | 化验单拍照→候选 | 「＋ 抄一次血钙/PTH」3 字段 | 参考区间照化验单并列，不计算"是否正常" |
| 症状打卡（麻木/呛咳/康复） | — | 打卡按钮（单字段日期自动） | 不归因；不做处理建议 |
| 症状日记（心悸/怕热/乏力） | 对话"下午心悸"→候选 | 「＋ 记一条症状」4 字段（日期/症状/强度 1–3/备注） | 强度轨道不画曲线不归因 |
| 复发/转移事件 | 报告解析→候选 | 「＋ 登记事件」4 字段（发现日期/部位/确认方式/备注） | 只登记医生告知过的事件；应对路径只列不荐 |
| 冷却期起算 | 复诊记录解析→候选 | ⋯→更正（登记新版本） | 倒计时只是日期算术；以医生意见为准（T7） |
| 材料 | —（清单为复诊材料要素，不 AI 生成） | 三态勾选（备齐/部分/未备齐） | 只整理复诊与报销材料；**THY 无职业病线** |
| 感受/FCR | 对话代记→候选（默认 private） | 「＋ 记一条感受」3 字段（内容/记录人/可见性） | 默认 private；配偶双源独立记录不代报 |
| 疑问清单 | 摘要生成→候选 | 「＋ 添加疑问」1 字段；勾选=已问 | 只整理不回答 |
| 试验收藏 | —（线索只陈列） | 收藏/取消收藏 | "登记状态，未核实"常驻；不是推荐 |
| 更正/删除 | 对话改数→候选 diff | 「⋯ → 改这一条」 | 更正=新增版本，旧记录保留（无"不可恢复"） |

收敛校验：每页显式编辑入口 ≤1（X3 实测：32 视图 × 2 档案全部 ≤1，`＋` 按钮或 `⋯` 菜单二选一）；表单最大 5 字段。
